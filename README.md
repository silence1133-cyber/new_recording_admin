* **docs/phase2-ia-rbac/**: 정보 구조도(IA) 및 권한 매트릭스
* **docs/phase3-process-flow/**: 컴플라이언스 업무 프로세스 플로우차트
* **docs/phase4-wireframes/**: 화면별 UI 와이어프레임 및 기능 명세서
* **docs/phase5-interfaces/**: 표준 REST API 및 감사 로그 스키마 규격서
