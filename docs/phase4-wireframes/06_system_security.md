# 4. 시스템 & 보안 관리 (Screen ID: SYS-01 ~ SYS-04)

## 1. 도메인 개요 및 공통 정책
* **도메인 목적**: 무제한 계층 조직 관리 및 고객사 CRM 동기화, 내선(Extension) 매핑, 엄격한 접속 IP 화이트리스트 기반 계정 관리, 불변 감사 추적(Audit Trail), 컴플라이언스 옵션 설정을 통합 제어한다.
* **적용 프레임워크**:
  * Multi-Tab Layout: 본문 상단 탭으로 다중 화면 전환 및 상태 보존
  * 테마: Deep Navy (#0A192F), Medium Navy (#1E293B), Pure White (#FFFFFF), High-Contrast Black (#0F172A)
* **공통 접근 권한 (RBAC)**:
  * `ROLE_SUPER_ADMIN`: 전체 시스템 설정, 계정 생성, IP 등록, 감사 로그 열람 및 보안 정책 수정 전권
  * `ROLE_AUDITOR`: 감사 로그(SYS-03) 전사 열람 및 보안 거버넌스 정책(SYS-04) 확인
  * `ROLE_OPS_ADMIN`: 조직 및 내선 조회(SYS-01 읽기 전용)
  * `ROLE_QA_LEAD`, `ROLE_AGENT`: 시스템 관리 메뉴 접근 전면 차단 (403 Forbidden)

## 3. 핵심 세부 기능 명세
1. **무제한 Depth 트리 & CRM 동기화**:
   * CRM 시스템과의 API 통신을 통해 계층 깊이 제한 없이 부서 구조를 동기화.
   * CRM에서 부서가 삭제된 경우, 과거 녹취 데이터 조회를 위해 DB에서 물리 삭제하지 않고 `[만료/비활성 부서 보관함]` 노드로 자동 이관(Soft Delete).
2. **내선 설정 및 배포 파이프라인**:
   * 내선 신규 등록 시 내선번호, 상담사, IP, 수집방식(CTI ROD/SIP) 지정.
   * 등록 정보는 `t_ExtInfo` 테이블에 즉시 반영되며, `VsCallManager` 스케줄러를 통해 각 수집 엔진에 자동 전파.

# 4.4 정책 & 스토리지 설정 (Screen ID: SYS-04)

## 1. 화면 개요
* **화면 경로**: `4. 시스템 & 보안 관리` > `4.4 정책 & 스토리지` (`/system/policies`)
* **화면 목적**: 컴플라이언스 기능 제어 옵션(Toggle)을 설정하고, 녹취 보존 수명주기(Lifecycle) 및 정부 마스킹 룰을 관리한다.

## 2. 화면 와이어프레임 레이아웃

### Section A. 컴플라이언스 기능 거버넌스 토글 (System Governance Toggles)
* **청취 사유 팝업 강제 (`OPT_PLAYBACK_REASON_POPUP`)**: `[ OFF (원클릭 청취) ]`
  * *설명: OFF 시 팝업 없이 즉시 재생되며, 감사 로그는 백그라운드에서 자동 기록됩니다.*
* **다운로드 결재 승인 단계 (`OPT_DOWNLOAD_APPROVAL_WORKFLOW`)**: `[ ON (결재 필수) ]`
  * *설명: ON 시 사유 작성 후 승인권자의 심사를 거쳐야만 암호화 다운로드가 활성화됩니다.*
* **실시간 감청 사유 팝업 강제 (`OPT_WIRETAP_REASON_POPUP`)**: `[ ON (사유 입력 필수) ]`
  * *설명: ON 시 감청 시작 전 사유 선택 모달이 팝업됩니다.*
* **마스킹 즉시 해제 권한 (`OPT_UNMASK_DIRECT_PERMISSION`)**: `[ OFF (승인제 가동) ]`
  * *설명: OFF 시 보안 감사관 결재 워크플로를 거쳐야만 마스킹이 임시 해제됩니다.*

### Section B. 보존 수명주기 및 스토리지 임계치 설정
* **녹취 파일 기본 보관 주기**: `[ 3년 (1,095일) ▼ ]` 경과 후 자동 파기 큐 이관
* **스토리지 임계치 경보 설정**:
  * 주의(Warning) 알림 기준: `[ 80 ] %` 사용 시 노란색 경보
  * 위험(Critical) 알림 기준: `[ 90 ] %` 사용 시 빨간색 경보 및 알림 발송
* **파기 정책**: 만료 데이터는 자동 즉시 삭제하지 않으며, `2.3 보존 및 파기` 화면에서 보안 감사관 승인 후 물리 삭제.

### Section C. 정부 공식 가이드라인 마스킹 규칙 확인 (Read-Only)
* 휴대폰: 가운데 4자리 마스킹 (`010-****-1234`)
* 일반전화: 국번 마스킹 (`02-***-1234`)
* 성명: 2자 끝자리 / 3자 가운데 / 4자 이상 앞뒤 제외 마스킹
* 주민번호: 앞 6자리 및 성별 코드 외 마스킹
