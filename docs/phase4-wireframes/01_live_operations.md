# 1.1 운영 대시보드 (Screen ID: OPS-01)

## 1. 화면 개요 및 목적
* **화면 경로**: `1. 실시간 모니터링` > `1.1 운영 대시보드` (`/ops/dashboard`)
* **화면 목적**: 콜센터 전사 인입 호, 상담 채널 가동 상태, 녹취 저장 스토리지 사용 현황, 시스템 이상 징후를 단일 뷰에서 실시간(실시간 폴링/웹소켓) 관제.
* **접근 권한 (RBAC)**:
  * `ROLE_SUPER_ADMIN`: 전사 데이터 조회, 시스템 자원 및 인프라 임계치 경보 확인
  * `ROLE_AUDITOR`: 읽기 전용 (보안 감사 지표 및 장애 로그 관제)
  * `ROLE_OPS_ADMIN`: 전사 통화 가동 지표 모니터링
  * `ROLE_QA_LEAD`: 소속 조직/부서 범위의 채널 가동 지표 모니터링
  * `ROLE_AGENT`: 접근 불가

## 3. 세부 기능 및 인터랙션 명세
3.1 상단 글로벌 컨트롤 바
새로고침 주기 선택 드롭다운:

옵션: 수동, 3초, 5초(기본값), 10초, 30초

설정된 주기에 따라 Section A, B, C 데이터를 백그라운드 REST API 비동기 폴링 호출.

수동 새로고침 버튼:

클릭 시 로딩 스피너와 함께 즉시 전체 지표 갱신.

3.2 통화 & 채널 가동 현황 (Section A)
등록 총 채널: 시스템에 등록되어 활성화된 전체 내선(채널) 수.

통화/녹취 중: 현재 RTP 세션이 수립되어 녹음 패킷이 인입 중인 채널 수.

대기 중 (Idle): 호가 연결되지 않은 유휴 상태 채널 수.

채널 가동율: (통화 중 채널 / 등록 총 채널) * 100 계산 표기.

녹취 성공률: 당일 누적 인입 통화 대비 정상 저장 완료율 ((정상 파일 생성 건 / 총 인입 통화 건) * 100). 99.0% 미만 하락 시 텍스트 색상 Red 전환.

3.3 조직별 채널 점유 현황 (Section B)
무제한 조직 연동:

CRM에서 승계된 최상위 노드(본부/실) 기준으로 프로그레스 바 렌더링.

하위 부서 필터 선택 시 해당 부서 노드 기준으로 채널 점유율 분기 표기.

점유율 프로그레스 바:

0~70%: Blue (#2563eb)

71~89%: Amber (#f59e0b)

90~100%: Rose (#e11d48)

3.4 스토리지 관제 & 수명주기 (Section C)
스토리지 사용량 게이지:

마운트된 음성 데이터 저장 디렉터리의 실제 가용 공간(Capacity) 대비 사용량 시각화.

Warning (80% 이상): 노란색 경고 위젯 표기.

Critical (90% 이상): 빨간색 위험 깜빡임(Blink) 알림 및 상단 GNB 벨 아이콘 배지 카운트 증가.

보관주기 만료 예정 알림:

라이프사이클 정책에 따라 24시간 이내 파기(자동 삭제) 예정인 녹취 파일 수와 용량 사전 표기.

3.5 실시간 이상 징후 및 감사 로그 (Section D)
이벤트 스트림 테이블:

최대 50건의 최신 시스템/보안 경보 및 주요 감사 이벤트를 역순(최신순) 정렬.

등급별 뱃지 표기:

INFO: 파란색 뱃지 (정상 동기화, 보존 연장 등)

WARN: 주황색 뱃지 (미인가 단일 IP 접근 차단, 채널 일시 무응답 등)

CRITICAL: 빨간색 뱃지 (스토리지 임계치 초과, 녹취 실패율 급증 등)

바로가기 링크 액션:

이벤트 항목 클릭 시 해당 도메인 상세 페이지(채널 관제 OPS-02, 감사 로그 SYS-03)로 검색 조건이 자동 주입된 상태로 라우팅.

## 4. 예외 케이스 및 화면 방어 정책
네트워크 단절 및 API 폴링 실패:

3회 연속 API 응답 실패 시 화면 중앙 상단에 토스트 팝업(서버와의 통신이 원활하지 않습니다. 재연결을 시도합니다.) 노출 및 재시도 백오프 적용.

미인가 IP 접근 시도 이벤트 감지:

상위 관리자 단일 IP 완전 일치 실패 이벤트 감지 시, 대시보드 접속 중인 ROLE_AUDITOR, ROLE_SUPER_ADMIN 화면에 실시간 긴급 토스트 경보 송출.
