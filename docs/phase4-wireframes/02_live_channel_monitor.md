# 1.2 실시간 채널 관제 (Screen ID: OPS-02)

## 1. 화면 개요 및 권한 정책

* **화면 경로**: `1. 실시간 모니터링` > `1.2 채널 관제` (`/ops/channels`)
* **화면 목적**: 시스템에 등록된 상담원 및 내선의 통화 상태(통화 중, 대기, 후처리, 이석, 오프라인)를 실시간으로 관제하고, 특정 통화에 대한 관리자의 실시간 감청(Live Wiretapping)을 제어한다.
* **적용 레이아웃 & 테마**:
  * Shell: Multi-Tab Container 상단 배치 (작업 상태 보존)
  * 테마: Navy (#0A192F, #1E293B) / Pure White (#FFFFFF) / High-Contrast Black (#0F172A)
* **접근 권한 (RBAC)**:
  * `ROLE_SUPER_ADMIN`: 전사 채널 조회 및 전사 감청 제어
  * `ROLE_AUDITOR`: 감청 실행 불가, 실시간 관제 현황 및 감청 감사 로그 추적만 가능 (읽기 전용)
  * `ROLE_OPS_ADMIN`: 전사 채널 조회 및 전사 감청 실행
  * `ROLE_QA_LEAD`: 소속 조직/팀 채널 조회 및 소속 팀원에 대한 감청 실행
  * `ROLE_AGENT`: 접근 전면 차단 (403 Forbidden)

## 3. 세부 컴포넌트 및 기능 명세

3.1 필터 및 관제 옵션 영역조직 선택 필터 (무제한 Depth 연동):
    CRM 시스템에서 승계된 최상위 본부부터 하위 파트까지 계층형 드롭다운 트리로 제공.
    상위 노드 선택 시 소속된 모든 하위 부서의 채널이 포함되어 렌더링됨.상태 필터 드롭다운:옵션: 전체(기본값), 통화중 (Talking), 대기중 (Idle), 후처리 (After-Call Work), 이석 (Away), 오류/비정상 (Error)뷰 전환 토글 
    버튼:카드 뷰 (Card View): 직관적인 상태 파악 중심 (1행에 3~4개 카드 배치).
    테이블 뷰 (Table View): 다량의 채널을 고밀도로 한눈에 파악할 수 있는 데이터 그리드 표 전환.

3.2 채널 상태 카드 UI/UX 가이드상태 구분카드 테두리 및 뱃지 스타일주요 표시 항목통화 중 (Talking)테두리: 
    Deep Navy (#0A192F), 뱃지: 녹색 (#10B981)상담원명, 내선, 채널번호, 고객 식별번호(마스킹), 실시간 통화 경과 시간대기 중 (Idle)
    테두리: Subtle Line (#CBD5E1), 뱃지: 파란색 (#3B82F6)상담원명, 내선, 대기 경과 시간후처리 (ACW)
    테두리: Subtle Line (#CBD5E1), 뱃지: 주황색 (#F59E0B)상담원명, 내선, 후처리 경과 시간장기 통화 경고
    테두리: Rose Red (#E11D48), 통화시간 깜빡임통화 시간이 설정 임계치(기본 10분)를 초과한 호 (감청 우선 대상)오류 (Error)
    테두리: Rose Red (#E11D48), 배경: 붉은색 틴트RTP 세션 단절, CTI 통신 실패 채널
    
3.3 실시간 감청 (Live Wiretapping) 모달 및 실행 명세① 감청 실행 흐름카드 내 [🎧 실시간 감청] 버튼 클릭 시, 시스템 거버넌스 옵션(OPT_WIRETAP_REASON_POPUP)을 확인한다.
    옵션 ON (기본값): 아래의 감청 사유 강제 입력 모달(OPS-02-M1)을 화면 중앙에 팝업한다.
    옵션 OFF: 팝업 없이 즉시 보안 WebRTC/오디오 스트리밍을 연결한다. (단, 감사 로그는 백그라운드 필수 기록)

③ 감청 오디오 재생 컨트롤 바 (Floating Audio Bar)
감청 시작 시 화면 하단에 고정된 슬림 Navy 오디오 바가 노출된다.

표기 항목: [🔴 실시간 감청 중] 상담원: 박민수 (2001) | 볼륨 조절 [■■■□□] | 청취 시간: 01:23 | [감청 종료]

상담원과 고객의 통화에는 관리자의 음성이 전혀 송출되지 않는 단방향 수신(Silent Monitoring) 모드로 수립된다.

개발자 도구(F12)에 실제 물리 미디어 주소가 노출되지 않도록 일회성 서명 토큰(Signed Token) 기반의 실시간 스트리밍 소켓을 사용한다.


## 4. 감사 로그 (Audit Trail) 연동 명세
실시간 감청이 실행되거나 종료될 때 SYS-03 (감사 로그) 테이블에 실시간으로 전송되는 필드 규격:

필드명,데이터 예시,설명
event_type,LIVE_WIRETAP_START / LIVE_WIRETAP_END,이벤트 식별자
actor_id,admin_hong,감청을 실행한 관리자 ID
actor_ip,10.240.40.100,관리자 실제 접속 IP (Exact Match 검증된 IP)
target_agent_id,agent_2001,피감청 상담원 사번
target_ext,2001,피감청 내선번호
reason_code,CUSTOMER_PROTECTION,선택된 사유 코드
reason_detail,10분 이상 장기 지연 호 발생에 따른 중재,입력된 상세 사유
session_duration,145 (초 단위),감청 유지 시간 (종료 시 기록)
