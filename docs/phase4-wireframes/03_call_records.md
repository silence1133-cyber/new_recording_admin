# 2.1 통합 녹취 이력 조회 (Screen ID: REC-01)

## 1. 화면 개요 및 목적
* **화면 경로**: `2. 녹취 이력 관리` > `2.1 녹취 이력 조회` (`/recordings/search`)
* **화면 목적**: 기간, 무제한 계층 조직 트리, 내선, 상담사, 고객 발/수신 번호 등 다차원 조건으로 저장된 통화 이력을 검색하고, 정부 가이드라인 비식별화가 적용된 그리드에서 원클릭으로 음성을 청취(HTML5 파형 플레이어)하며 파일 반출 신청을 수행한다.
* **적용 프레임워크**:
  * Multi-Tab Layout: 본문 상단 탭으로 렌더링 (검색 필터 및 페이지 상태 유지)
  * 테마: Navy (#0A192F, #1E293B) / Pure White (#FFFFFF) / High-Contrast Black (#0F172A)
* **접근 권한 (RBAC)**:
  * `ROLE_SUPER_ADMIN`: 전사 이력 조회
  * `ROLE_AUDITOR`: 전사 이력 조회 (청취 시 감사 로그 백그라운드 필수 기록)
  * `ROLE_OPS_ADMIN`: 전사 이력 조회
  * `ROLE_QA_LEAD`: 소속 조직/팀 통화 이력만 조회 (타 부서 데이터 접근 차단)
  * `ROLE_AGENT`: 본인 통화 이력만 조회 (타인 데이터 열람 전면 차단)

## 3. 세부 기능 및 인터랙션 명세

### 3.1 다차원 복합 검색 (Section A)
* **일시 범위 선택**: 시작일 및 종료일(Date Picker), 빠른 선택 칩(당일, 1주일, 1개월, 당월). 기본값은 당일 00:00:00 ~ 23:59:59.
* **무제한 계층 조직 트리**: CRM 승계 조직 트리 노드를 재귀 드롭다운으로 선택. 상위 부서 선택 시 하위 소속 모든 부서의 통화 건이 자동 포함됨.
* **고객번호 검색**: 입력창에 번호 입력 시 정부 마스킹 이전의 원본 인덱스를 기반으로 백엔드 매칭 검색 지원.
* **검색 실행**: Enter 키 또는 [검색 실행] 버튼 클릭 시 Section C 그리드 갱신.

### 3.2 데이터 그리드 및 마스킹 (Section B & C)
* **정부 공식 가이드라인 비식별화 렌더링**:
  * 휴대폰 번호: 가운데 국번 4자리 마스킹 (010-****-5678)
  * 유선 전화: 가운데 국번 마스킹 (02-***-1234)
  * 고객 성명: 2자 홍*, 3자 홍*동, 4자 이상 남***우
* **원클릭 스트리밍 재생 ([🎧 청취] 액션)**:
  * 사유 입력 팝업 없이 즉시 오디오 재생 시작 (업무 효율 극대화).
  * 재생 버튼 클릭 시 Section D 하단 플레이어가 부드럽게 슬라이드 업(Slide-up)됨.
  * 백그라운드 감사 로그 자동 저장: 클릭 즉시 청취자 ID, 대상 Call ID, 접속 IP(Exact Match 검증값), 타임스탬프를 SYS-03 감사 테이블에 기록.
* **보존 상태 표시 (Legal Hold)**:
  * 소송, 금융 분쟁 등의 사유로 보존 연장이 지정된 건은 [LegalHold] 배지(Navy 색상) 표시. 해당 건은 스토리지 자동 파기 대상에서 영구 제외됨.

### 3.3 HTML5 파형 오디오 플레이어 (Section D)
* **보안 스트리밍 세션**:
  * 브라우저 개발자 도구(F12) 네트워크 탭에서 음성 파일의 디스크 저장 경로 노출 전면 차단.
  * 30분 동안 유효한 일회성 암호화 서명 토큰(Signed Token) 기반 Blob 스트리밍 사용.
* **파형 제어 인터랙션**:
  * Canvas 기반 볼륨 진폭(Waveform) 시각화. 특정 위치 클릭 시 해당 재생 시점으로 즉시 이동(Seek).
* **재생 컨트롤러**:
  * 배속: 0.8x, 1.0x (기본), 1.2x, 1.5x, 2.0x
  * 탐색 단축키: 5초 전/후 이동, 스페이스바로 재생/정지.
  * [구간 반복]: 특정 구간(A-B) 루프 재생 지원.
  * [통화 메모]: 관리자 의견 입력 레이어 팝업 (통화 메타데이터 귀속).

### 3.4 반출(다운로드) 신청 연동 (컴플라이언스 강제)
* 그리드 좌측 체크박스로 단건 또는 다건(최대 100건) 선택 후 [선택 반출(다운로드) 신청] 클릭.
* **반출 사유 강제 입력 팝업(REC-02-M1) 호출**:
  * 사유 미입력 시 다운로드 단계 진입 불가.
  * 시스템 옵션(OPT_DOWNLOAD_APPROVAL_WORKFLOW) 상태에 따라:
    * ON (승인제): 결재 요청 생성 후 2.2 반출/다운로드 관리(REC-02) 화면으로 이관.
    * OFF (직접반출): 사유 감사 로그 저장 후 일회성 암호화 압축 파일 다운로드 큐 생성.

## 4. 예외 처리 및 성능 가이드
1. **대용량 조회 최적화**:
   * 기본 페이징은 서버 사이드(Offset/Limit) 방식으로 처리하며, 단일 쿼리 최대 조회 건수는 10,000건으로 제한(추가 건수는 기간 필터 조정 유도 안내).
2. **미디어 스트리밍 실패 시**:
   * 파일 손실 또는 스토리지 마운트 단절 시 플레이어 영역에 `[오디오 파일을 불러올 수 없습니다. (스토리지 상태 확인 필요)]` 에러 메시지 표기 및 관리자 경보 발송.
